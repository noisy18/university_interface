# СТОПСПАМ — анализатор подозрительных сообщений

**СТОПСПАМ** — веб-приложение для проверки подозрительных сообщений из мессенджеров, электронной почты и социальных сетей с помощью машинного обучения.

Сервис помогает пользователям распознавать спам, фишинговые сообщения и другие виды интернет-мошенничества. После проверки пользователь получает вердикт, объяснение обнаруженных признаков риска и рекомендации по безопасным действиям.

### 2. Практика №3 — Визуальный концепт

Папка: `design/practice-3/`

Цель практики — разработка визуального концепта основного пользовательского сценария на основе брифа проекта.

В рамках практики:

- Разработаны ключевые экраны веб-приложения.
- Определены основные элементы интерфейса.
- Подобраны шрифты и цветовая палитра.
- Определена система отступов и выравнивания.
- Проведена проверка интерфейса по чек-листу из 10 пунктов.

Основные экраны:

- Ввод подозрительного сообщения.
- Результат анализа ML-модели.

Дополнительно предусмотрены состояния загрузки, ошибки и различные результаты проверки.

**Основные требования:** Desktop 1440 px, единая визуальная концепция, понятная иерархия элементов и доступность интерфейса.

### 3. Практика №4 — Дизайн-система

Папка: `design/practice-4/`

Цель практики — выделить из разработанных экранов единую дизайн-систему и повторно собрать интерфейс на основе общих компонентов.

В рамках практики:

- Определены цветовые токены (до 15 цветов).
- Создана шкала отступов и радиусов.
- Определены текстовые стили.
- Разработаны 5–7 переиспользуемых компонентов со всеми состояниями.
- Пересобраны экраны пользовательского сценария на основе компонентов.
- Продуманы состояния экрана результата: пустое, загрузка, ошибка и результат.
- Проведён стресс-тест интерфейса — проверка отображения результатов с различным содержанием и объёмом текста.

**Основная задача:** обеспечить единообразие интерфейса, повторное использование компонентов и удобство дальнейшей разработки.

## Принцип работы StopSpam

1. Пользователь вставляет подозрительное сообщение в поле ввода.
2. Система анализирует текст с помощью ML-модели и дополнительных правил.
3. Определяется категория сообщения и уровень риска.
4. Пользователь получает объяснение обнаруженных признаков.
5. Сервис предлагает рекомендации по безопасным действиям.

### Возможные результаты проверки

- **Спам** — нежелательное массовое сообщение.
- **Фишинг** — сообщение с признаками попытки получить личные данные.
- **Подозрительно** — обнаружены потенциально опасные признаки.
- **Вероятно безопасно** — явных признаков угрозы не обнаружено.

_Результат анализа является рекомендацией и не гарантирует абсолютную безопасность сообщения._
